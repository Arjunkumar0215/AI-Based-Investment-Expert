# Rule Based-Investment-Expert
🚀 **Built My Own AI-Based Investment Expert 💼📊**

I’m excited to share one of my latest projects — a **Rule-Based Investment Expert System** designed to recommend a portfolio allocation based on factors like **age, investment horizon, and risk tolerance**.

💡 **What makes this project different?**

This is not a recommendation copied from an online financial calculator. The allocation logic is based on **my personal rule-based thought process developed from my experience and learning in the financial market**.

The system considers different investor profiles and distributes investment across:

📈 Stocks
📊 Mutual Funds
🥇 Gold/Silver
🏦 Bonds/FDs

For example, the system adjusts the allocation depending on whether an investor has a **Low, Moderate, or High risk profile** and whether the investment horizon is short, medium, or long term.

🛠️ **Tech Stack**
• Python
• Streamlit
• Pandas
• Matplotlib
• Rule-Based Expert System

🎨 **UI/Frontend**
I designed and improved the interactive Streamlit interface with the help of **ChatGPT**, focusing on making the dashboard cleaner, simpler, and more user-friendly.

✨ The project includes:
✅ Dynamic portfolio allocation
✅ Investment amount calculation
✅ Interactive risk & horizon selection
✅ Portfolio visualization
✅ Income-based investment view
✅ Downloadable investment report
✅ Automatic validation to ensure portfolio allocations total **100%**

This project helped me understand how **financial knowledge + programming + AI-assisted development** can be combined to build practical decision-support applications.

⚠️ **Important:** This is a **personal rule-based experimental project**, created for educational and learning purposes. It is **not financial advice** and does not guarantee investment returns.

I’m continuing to improve this project and explore how it can become a more intelligent **AI-powered financial decision-support system**.
